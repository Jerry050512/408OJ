# 408OJ

面向 **408 计算机学科专业基础综合**备考的本地在线评测系统（Online Judge），
专注数据结构算法设计大题：真题驱动、考点拆解、考场级 C 语言合规约束。

![tech](https://img.shields.io/badge/stack-FastAPI%20%2B%20SQLite%20%2B%20GCC-6c6ff2)

## 功能特性

- **历年真题** — 收录 2012–2026 全部 408 数据结构算法设计大题（第 41 题为主，
  含 2012-42、2016-43），改造为标准输入输出格式，可在线评测。
- **408 合规检查** — 提交前静态检查源码：头文件白名单（标准/严格两级）、
  禁用文件 I/O、进程/系统调用、`gets`、`qsort`、`bsearch`，
  模拟考场"只允许基础库"的约束；违规直接判 CE 并给出逐行说明。
- **真实评测** — GCC（C11 `-O2 -Wall`）编译，逐测试点运行，
  超时/运行时错误/答案错误精确判定，统计耗时与峰值内存。
- **考点练习** — 26 道把大题考点拆解的小题（链表三部曲、栈与出栈序列、KMP、
  树遍历重建、图遍历、拓扑排序、堆、归并……），按重要度 ★1–5 标注。
- **逐题题解** — 考点定位、设计思想、分步实现、复杂度分析、考场提示、参考实现。
- **现代界面** — 自研设计系统 v2「墨底工坊」：中性灰阶主导 + 单一工程蓝 accent，
  参照 Linear/GitHub 的高级感设计语言，刻意规避 AI 味（无渐变/无玻璃态/无 emoji）；
  深/浅双主题、离线语法高亮代码编辑器、回车智能缩进、草稿自动保存、
  样例一键运行、自定义输入试跑。设计调研与决策见 docs/design-notes.md。
- **学习统计** — 章节掌握度、真题年份进度、考点频次、提交记录与评测详情
  （失败测试点给出输入/期望/实际三方对比）。

## 快速开始

```bash
pip install -r requirements.txt
python run.py                 # http://127.0.0.1:8408
```

要求：Windows/Linux/macOS，Python ≥ 3.10，系统 PATH 中存在 `gcc`（C 评测用）。
首次启动会自动建库并写入全部 42 道题目。

常用参数：`python run.py --port 9000` / `--db db.sqlite` / `--reseed`（重建题库）。

## 运行测试

```bash
python -m pytest tests/ -q        # 全部 ~60 项（含 42 题参考解 AC 集成验证，约 1 分钟）
python -m pytest tests/ -q -m "not slow"   # 跳过参考解逐题验证的快速集
```

## 技术栈与架构

见 [docs/PLAN.md](docs/PLAN.md)。要点：

- 后端 FastAPI + SQLite（服务端渲染 Jinja2），无外部静态资源依赖，离线可用；
- `oj/policy.py` 408 源码合规静态检查；`oj/judge.py` 编译/运行/比对引擎；
- `oj/content/` 题库内容（题面、题解、参考解 C、测试生成器），
  `oj/seed.py` 用 Python 参考实现生成期望输出并做样例一致性校验；
- `tests/` 覆盖合规检查、评测引擎、题库完整性、页面/API、端到端提交。

## 目录约定

学生数据（提交记录、题库库文件）默认存于 `data/oj.db`；评测临时文件在 `.judge_tmp/`，
两者均已加入 `.gitignore`。
