## 4. 2027 年出题预测

### 4.1 算法设计大题预测

**高概率（>70%）：**

1. **链表操作回归** — 链表大题自 2019 年后已缺席 7 年，是历史最长空窗期。
   预测方向：分组逆置、区间删除、奇偶重排等组合操作。

2. **树+递归** — 2022/2026 连续考 BST，递归区间法已成定式。
   预测方向：BST 第 k 小、BST 删除、平衡判定、对称判定。

**中概率（40-70%）：**

3. **图应用深化** — 2021-2024 图题密集，2025 暂歇但趋势未断。
   预测方向：欧拉回路构造、最短路径变体、割点/桥。

4. **数组一次遍历** — 2025 刚考，但该模式灵活度高，换皮重考概率不低。
   预测方向：前缀/后缀信息、滑动窗口、原地哈希变体。

**低概率但值得关注（20-40%）：**

5. **排序应用** — 2016 后未出排序大题，堆/快排应用可能回归。
6. **查找应用** — 散列表/二分查找大题从未出现，但选择题高频。

### 4.2 选择题必考考点

- 排序算法（每趟确定元素、稳定性、比较次数）
- 二叉树遍历（先中后序组合、线索化）
- 复杂度分析（递归式、主定理）
- 入栈出栈序列 / 卡特兰数
- cache 映射与命中
- IEEE 浮点数表示
- 虚拟页式管理 / 缺页

## 5. 模拟题设计说明

基于以上分析，408OJ 新增以下模拟题：

### 5.1 模拟大题（18 道，kind="mock"）

覆盖线性表(7)、树(5)、图(4)、排序/查找(2)，
每道题均标注预测依据与对应真题关联。

### 5.2 子算法拆解题（20 道，kind="practice"）

将模拟大题的复合技能拆解为可独立训练的原子操作：
- 链表：分组计数、区间逆置、删除、公共结点、奇偶重排
- 数组：区间逆置、去重、循环移位、最长递增子序列、摩尔投票
- 树：BST第k小、叶子计数、对称判定、结点统计、BST删除
- 图：出入度、欧拉判定、树判定、环检测、连通分量

### 5.3 设计原则

1. **真题驱动**：每道模拟题可追溯到至少一道历年真题的考点或技巧
2. **难度梯度**：difficulty 1-3 对应基础/中等/进阶，与真题难度分布一致
3. **408 合规**：所有 C 参考解遵循考场约束（标准头文件、无文件 I/O）
4. **子技能可组合**：大题 = 若干子技能的组合，练习题可独立训练
5. **原创性**：题目描述与数据均原创，不复制真题原文
