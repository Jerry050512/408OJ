## 业界的"高级感"设计系统（参考对象）

| 对象 | 可借鉴的手法 |
|---|---|
| Linear | 近乎纯黑的中性墨底 + 发丝级 1px 边框；彩色只给品牌小点与状态；11px 大写微型标签做分区 |
| Vercel/Geist | 黑白两极对比 + 单个蓝色 accent；5–6px 小圆角；密集数据表格 |
| GitHub (dark) | 中性灰阶面板分层（bg/panel/inset）、`#21262d` 发丝边框、语义色只描述状态；工程工具气质最适合 OJ |
| 主流 OJ（Codeforces/LeetCode） | 高信息密度、弱装饰；判定结果色是唯一的强颜色 |

共通规律：**中性色主界面 + 小面积 accent + 语义色只表达状态 + 微小圆角 + 无 gradient、无 glow、无 emoji**。

## 408OJ v2 设计语言 —— "墨底工坊 (Ink Terminal)"

1. **中性灰阶主导**：深色以 GitHub-dark 灰阶为基准（bg `#0d1117` / panel `#161b22` / inset `#010409`），浅色以 GitHub-light 为基准；双主题共用一套层级。
2. **单一 accent = 工程蓝**（dark `#4493f8` / light `#0969da`）：只用于链接、主按钮、active 态、logo。删除一切紫粉渐变。
3. **语义色只表达状态**：AC 绿 / WA 红 / TLE 琥珀 / RE 紫 / CE 灰；难度三色；重要度金色 ★。界面其余部分保持单色。
4. **圆角 6px、发丝边框、无 hover 位移、无渐变阴影**。交互反馈 = 边框/底色变化。
5. **排版**：正文 14px；标题 -0.01em 字距；分区用 11px uppercase mono 标签；数据/编号/时限一律等宽字体，与正文形成"代码工坊"气质对比。
6. **图标一律 SVG，禁用 emoji**。
7. **Logo 语义化**：accent 方块 + mono 白字 `41` —— 408 数据结构算法设计题的题号，属于考生的梗；导航文字标 "408OJ"。
8. **文案去营销腔**：事实陈述（多少题、什么标准、怎么评测），不说"赋能/极致/丝滑"。
9. **编辑器与静态代码块双主题恒为深色**（IDE 语境），样例/正文代码块随主题。

## v1 → v2 的映射

- 渐变文字 hero → 素色标题 + mono kicker 标签
- 渐变 stat 条 → 3px 纯色进度条
- 脉冲圆点"本地评测已就绪" → nav 右侧 muted mono 文字 `gcc · local`
- mac 三点窗口 → 纯文字工具栏（文件名 + 限制 chips）
- emoji 空状态 → 发丝虚线框 + 一句人话
- translateY hover → 边框/底色微变
